# Story 2.2: Remove Return of Capital handling

Status: ready-for-dev

## Story

As a developer,
I want every separate handling of "Return of Capital" removed and consolidated under Dividend,
So that the app models a single income concept per the PRD glossary and AD-7.

## Acceptance Criteria

1. `scripts/seed-postgres.ts` no longer seeds a `divDepositType` named "Return of Capital". The `seedDivDepositTypes` array contains exactly: Dividend, Interest, Capital Gains.
2. `docs/data-models.md` no longer lists "Return of Capital" as an example deposit type in the `divDepositType` model documentation (line 222 comment).
3. A repository-wide search (case-insensitive) for "return of capital" outside `_bmad-output/` returns zero matches.
4. The seed script still runs successfully via `tsx scripts/seed-postgres.ts` and seeds the remaining 3 types without error.
5. The server canonical seed (`get-top-div-deposit-types.function.ts`) is unchanged and still seeds exactly "Dividend" + "Deposit".
6. Story 2.1 unit tests (once implemented) pass: `nx test server` green, `scripts/seed-postgres.spec.ts` green.

- Cites AD-7 (Dividend/Deposit only; "Return-of-capital is folded into dividend"), AD-1 (layered route-domain → Prisma direct), FR-5, FR-6, FR-7.
- The removal surface is exactly 2 lines: `scripts/seed-postgres.ts:97` and `docs/data-models.md:222`. No client code, server route, or spec hardcodes "Return of Capital" — the client renders type names dynamically from DB data.

Once "Return of Capital" is removed from the DB seed, it will no longer appear in the UI. No client code change needed.

- The `div-deposit-types` route (`apps/server/src/app/routes/div-deposit-types/index.ts`) has only a POST route for listing types by id. No add/delete/update routes exist. No route changes needed.
