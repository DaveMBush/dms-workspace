# Story 2.1: Unit tests for removing Return of Capital

Status: skip

## Story

As a developer,
I want a red-phase unit-test scaffold asserting the `divDepositTypes` seeding no longer emits a "Return of Capital" type,
So that the implementation story has a defined contract to make pass.

## Acceptance Criteria

1. A new spec file `scripts/seed-postgres.spec.ts` asserts that `seedDivDepositTypes` produces an array with no entry named "Return of Capital".
2. The same spec asserts the seeded type array contains exactly: Dividend, Interest, Capital Gains (three entries, no Return of Capital).
3. A new spec file `apps/server/src/app/routes/top/get-top-div-deposit-types.function.spec.ts` asserts the canonical server seed still creates exactly "Dividend" and "Deposit" when the table is empty.
4. Both specs pass with `nx test server` and the seed script spec runs under the root Vitest configuration.

## Tasks / Subtasks

- [ ] Task 1 (AC: #1, #2): Create `scripts/seed-postgres.spec.ts` with Vitest + a mocked Prisma client (`vi.mock('@prisma/client')`).
  - [ ] 1.1 Extract or re-export `seedDivDepositTypes` as a testable function (or test via the class with a mocked `this.prisma`).
  - [ ] 1.2 Assert `prisma.divDepositType.upsert` is called with exactly 3 calls (Dividend, Interest, Capital Gains).
  - [ ] 1.3 Assert no call has `name: 'Return of Capital'`.
- [ ] Task 2 (AC: #3): Create `apps/server/src/app/routes/top/get-top-div-deposit-types.function.spec.ts`.
  - [ ] 2.1 Mock Prisma: `divDepositType.findMany` returns `[]` → assert `create` called with "Dividend" and "Deposit".
  - [ ] 2.2 Mock Prisma: `divDepositType.findMany` returns non-empty → assert no `create` calls, response contains all ids.
  - [ ] 2.3 Assert no "Return of Capital" string appears in any created or returned type.
- [ ] Task 3 (AC: #4): Verify both spec files run green under `nx test server` (the server Vitest executor in `apps/server/project.json`).

## Dev Notes

- Status is `skip`: this is a red-phase scaffold ordered before Story 2.2. The test for the seed script will initially FAIL (red) because "Return of Capital" is still present in the source. Story 2.2 makes it pass.
- Cites AD-7 (Dividend/Deposit only; RoC folded into dividend), FR-5, FR-6, FR-7 from PRD.
- The seed script uses `tsx` direct execution (`#!/usr/bin/env tsx`, line 1 of `scripts/seed-postgres.ts`). It is not wired to any `package.json` script or `nx` target. For testability, the class method `seedDivDepositTypes` (lines 90–109) should be importable. If the current class structure makes direct import awkward, extract the type-array constant or the method into a small exported function.
- The server spec targets `apps/server/src/app/routes/top/get-top-div-deposit-types.function.ts` (32 lines). It uses `prisma.divDepositType.findMany` and `prisma.divDepositType.create`. No existing spec covers this file.
- Vitest 4.1.0 is the workspace test framework. Server tests run via `nx test server` (executor `@nx/vitest:test`, `passWithNoTests: true`).
- AD-7 explicitly states: "Return-of-capital is folded into dividend; there is no 'Interest' type." The seed script currently includes "Interest" and "Capital Gains" which AD-7 flags as drift. This story does NOT remove those — only "Return of Capital". Removing Interest/Capital Gains is a separate concern (see Deferred in ARCHITECTURE-SPINE).
